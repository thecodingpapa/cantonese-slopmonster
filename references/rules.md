# 檢查器範圍與規則 v0.1

`tools/check.py` 只讀檔、冇網絡請求、唔會改稿。需要 Python 3.10+，只用標準函式庫。JSON 用 UTF-8；行、欄由 1 開始，欄位係 Unicode 字元位置，唔係螢幕寬度。原始位置 `start/end` 係 Python 字串索引。

## 有乜提示

| ID | 類別 | 提示條件 | 常見合理例外 |
|---|---|---|---|
| R101 | register 語體 | 我們／你們／他們等代詞 | 專名、正式原話 |
| R102 | register 語體 | 這個／那些／什麼／怎麼等用語 | 引述、刻意用另一種語體 |
| R103 | register 語體 | 沒有／正在／能夠／讓我們 | 技術或正式語境；共通中文 |
| R104 | register 語體 | 綜上所述／本文將等論文句式 | 評論文本本身 |
| R105 | register 字形 | 有限嘅疑似簡體字清單 | 專名、原文；唔涵蓋全部繁簡字 |
| W201 | writing 表達 | 無縫體驗／革命性等宣傳用語 | 有根據嘅字面意思、歷史題材 |
| W202 | writing 表達 | 在這個…時代／開啟…之旅等鋪排 | 確有交代時代或旅程嘅作用 |
| W203 | writing 表達 | 去除標點空白後，相同嘅 ≥8 漢字句段再出現 | 重點回顧、對話、副歌 |
| W204 | writing 節奏 | 同一行句段 >90 漢字而未遇句末標點或排除區 | 長引用、刻意長句；人工朗讀先決定 |
| W205 | writing 節奏 | 連續 ≥4 個列入字表嘅語氣詞 | 對話表演、擬聲等特殊用途 |

實際字表同 regex 喺 `tools/rules.json`；重複／長句邏輯喺 `tools/check.py`。門檻係手訂實用值，唔係從香港人口統計或語料頻率學返嚟。所有提示都係覆核建議，唔係語法判決。無使用 machine learning、AI 偵測或模型 API。

## 檢查範圍

預設讀 Markdown 同純文字口述稿。略過 Markdown 標題、`>` 引文、程式碼圍欄、行內 code、圖片、註解、連結目的地，以及成對嘅「」、『』、“”、‘’、英文雙引號和獨立英文單引號內容。保留 Markdown 連結可見文字做檢查。呢個係簡化解析器，唔支援完整 Markdown、HTML、DOCX、PDF 或字幕格式；先匯出 UTF-8 `.md`／`.txt`。

以下拍攝提示會略過：`[00:10]`、`[畫面：...]`、`[字幕：...]`、`[停頓]`、`【B-roll：...】`，以及鏡頭、音效、音樂、轉場、SFX、CUT 前綴。普通括號同未識別方括號仍會檢查，避免將旁白藏起。冇標記嘅專名或術語可能誤報，請按上下文保留。

用 `--include-quotes` 可檢查引號及 `>` 內嘅文字（例如係你自己寫嘅角色對白）；佢唔會取消 code、標題同拍攝提示排除。`--format plain` 關閉 Markdown 特有排除，引號、網址、拍攝提示仍然排除。所有排除數量會顯示；全篇都排除時唔會當合格。

## Coverage 同退出碼

- `checked`：≥8 漢字並出現有限字表內嘅廣東話標記。呢個只係弱提示，唔係語言鑑定；一個「嘅」唔足以證明全篇係廣東話。
- `review_language`：有漢字，但未見字表內廣東話標記。共通中文都可能落入呢類，唔好硬加語氣詞過關。
- `mixed_language`：偵測到日文假名或韓文字母，只能局部檢查。英文術語可以自然混用；純英文唔受支援。無法可靠分辨純漢字日文或所有混合語言。
- `insufficient`：少於 8 漢字；`unsupported`：冇漢字；`empty`：冇可檢查字母或數字。
- `review_markup`：發現未配對標記；修正後重跑。未結束圍欄會略過餘下內容；未配對引號會保留內容作檢查並提醒。

退出碼 `0` 只表示 coverage 為 checked 並且冇命中有限規則；`1` 表示有提示或範圍未確定；`2` 表示無旁白、檔案／編碼／用法錯誤。唔設 5/5、百分比或者自動發佈門檻。JSON 嘅 `meaning_verified` 永遠係 `false`。

## 前後稿對照

`tools/preserve.py before.md after.md --lock 'Rain is here'` 比較阿拉伯數字（包括全形）、網址、已識別引文／code／拍攝提示／連結目的地及手動 lock 嘅出現次數。會同時提示新增同刪除；即使只係改數字格式，都會保守地提示。新增章節時間碼亦會提示，要人手判斷。

中文數字、單位、人物關係、否定、論點同未標記專名唔會自動保證保留。重要資料可用重複 `--lock` 指定完整字串，例如 `--lock '30 分鐘' --lock '不適用於急症'`；如果原稿冇呢段文字，工具會報 invalid_input，唔會默默忽略。

對照退出碼：`0` anchors_unchanged；`1` changed（包括標記警告）；`2` invalid_input／讀檔錯誤。保持原稿嘅意思仍然需要人手核對，唔係保留字眼就等於意思一樣。
