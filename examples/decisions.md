# 有提示，唔等於一定要改

以下全部係本項目 AI 原創例句，未經獨立母語編輯評核。

| 初句 | 決定／修訂 | 原因 |
|---|---|---|
| 我們會展示這個設定。 | 我哋會示範呢個設定。 | 改口述句法，意思保持 |
| 我哋需要兩個轉插，因為插頭唔啱。 | 保留 | 「需要、因為」係自然共通詞，唔使逐字避開 |
| 佢話「我們沒有收到通知」。 | 引文保留 | 呢句係被引用嘅原話 |
| 呢個 app 會用 API 傳資料。 | 保留 | code-switching 可以自然 |
| 呢個方法可能幫到你，但未必人人啱用。 | 保留限制 | 唔改成「呢個方法一定幫到你」 |
| 呢度講緊一場革命性嘅轉變。 | 先核對上下文 | W201 只要求覆核；歷史描述可能有字面根據 |
| 10 分鐘做完，20 分鐘休息。 | 唔可以交換兩個數值 | 數字集合相同都可以改咗意思 |

`before.md` 同 `after.md` 係短教學片段，示範資料固定為 10 分鐘。`example.com` 係示意網址，唔係證據；「專注模式」係虛構畫面文字。呢啲設定只屬例子，唔係 Rain is here 嘅主題、實際片長、經歷或者產品建議。
